# IAIndustria4.0 - Secure IoT & AI System

Proyecto de grado para la implementación de un sistema de monitoreo y control industrial con Inteligencia Artificial, diseñado para operar bajo estándares de seguridad **End-to-End TLS (HTTPS/MQTTS)**.

## 🚀 Inicio Rápido

Para entender cómo funciona el sistema, consulta la documentación detallada:
👉 **[ARCHITECTURE.md](./ARCHITECTURE.md)**

## 📂 Componentes Principales
*   **Esp32/**: Firmware para dispositivos de campo.
*   **Servidor/**: Backend en Node.js con IA y Sockets.
*   **Plc/**: Frontend moderno en React para el Dashboard.
*   **Documentacion/**: Tesis y archivos de sustento (LyX).
